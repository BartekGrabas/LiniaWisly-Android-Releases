# Linia Wisły — aplikacja Android

Aplikacja Linia Wisły służy do przekazywania zgłoszeń z telefonu Android.

## Pobieranie

[Pobierz najnowszą wersję APK](https://github.com/BartekGrabas/LiniaWisly-Android-Releases/releases/latest/download/linia-wisly.apk)

## Instalacja i aktualizacja

1. Pobierz plik `linia-wisly.apk`.
2. Android może poprosić o zezwolenie na instalowanie aplikacji z tego źródła.
3. Zatwierdź instalację.
4. Przy następnych aktualizacjach instaluj nowe APK na istniejącej aplikacji.
5. Nie odinstalowuj poprzedniej wersji, jeżeli chcesz zachować lokalne dane.

Aplikacja Linia Wisły znajduje się obecnie na etapie testów.
